Install
Totally.

Choose an install method. Totally will be ready on your PATH.

$ curl -fsSL https://totally.sh/install.sh | sh
$ go install github.com/rybkr/totally/cmd/totally@latest

Defaults to ~/.local/bin. Set TOTALLY_INSTALL_DIR to install elsewhere, for example TOTALLY_INSTALL_DIR=/usr/local/bin.
