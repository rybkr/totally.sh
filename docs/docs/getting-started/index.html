Getting started

Install Totally with the shell installer:

curl -fsSL https://totally.sh/install.sh | sh

The installer places the executable in ~/.local/bin by default. Set TOTALLY_INSTALL_DIR to choose another directory.

If you have Go installed, you can also install the latest version directly:

go install github.com/rybkr/totally/cmd/totally@latest

Run a first usage report:

totally stats --since 7d

Then list the sessions Totally found:

totally sessions

Totally discovers supported local agent homes automatically. Use --home when you want to inspect a specific location or combine more than one location.

totally --home ~/.codex sessions
totally --home ~/.codex --home /path/to/another-agent stats --since 30d

Use totally --help or totally <command> --help to see the flags supported by your installed version.
