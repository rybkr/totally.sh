Totally reads local agent-session transcripts and turns them into useful reports
about activity, tokens, estimated cost, models, and stored files.

Start with [Getting started](getting-started/) to install the CLI and run your
first report. Use [Sessions](sessions/) to find work, [Stats](stats/) to compare
usage, and [Pricing](pricing/) to review the assumptions behind cost estimates.
